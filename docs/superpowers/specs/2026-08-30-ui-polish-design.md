# 长条、趋势与配对设置界面优化设计

## 目标

在不改变额度、Token、任务状态或配对行为的前提下，统一桌面端与网页版文案，并优化趋势区域与配对按钮的视觉表现。

## 范围

- 长条桌面端和网页版：将“周额度剩余”改为“周剩余”；将“5小时额度可用”改为“5小时额度”。
- 趋势区域：保留现有按天滚轮切换、横向拖拽和 7 天数据窗口；隐藏浏览器原生横向滚动条，不引入新的数据处理。
- 配对设置：仅调整“重置配对”按钮的视觉样式，使其与“立即更新”按钮使用同一套圆角、浅绿色、阴影和字体规则。

## 不变项

- 不修改 Snapshot、额度字段、Token 字段、任务状态机、采样频率、历史窗口逻辑或配对请求。
- 网页端继续使用现有独立渲染逻辑，只同步显示文案和滚动条样式。

## 验收

- 桌面长条和网页长条均显示“周剩余 N%”及“5小时额度”。
- 趋势切换到 5、6、7 天时仍可横向拖拽，页面不出现原生横向滑轨。
- 配对设置中的“重置配对”按钮与“立即更新”在视觉上协调，点击行为不变。
- TypeScript 构建和现有 UI 测试通过；本地预览截图确认三处改动。
