# 设备验收清单

## Windows

- [ ] 安装 NSIS 包后看到桌面悬浮球和托盘图标。
- [ ] 拖动悬浮球后重启应用，位置保持。
- [ ] 点击悬浮球展开详情，验证重置时间、套餐、重置机会和本日 Token。
- [ ] 托盘可显示/隐藏、立即更新、切换开机自启和退出。

## iPhone / Kindle（同一 Wi‑Fi）

- [ ] 从 Windows 详情复制带 `pair=` 的地址，在 Safari/Kindle 浏览器打开。
- [ ] 看到相同的周额度、任务状态和本日 Token。
- [ ] 断开 Wi‑Fi 后看到明确失败提示，恢复后自动重连。
- [ ] 绿色完成任务点击“已验收”后只隐藏本地记录，不影响 Codex 原任务。
- [ ] 320px 宽度、768px 宽度下文字不被截断；关闭 JavaScript 时看到回退提示。
